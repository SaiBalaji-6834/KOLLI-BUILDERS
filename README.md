# KOLLI BUILDERS

### Construction Management & Customer Support Platform

KOLLI BUILDERS is a web-based construction management platform designed to streamline customer interactions, building requests, blueprint approvals, and support ticket management.

## Features

- Company website and project information
- Customer and staff login
- Admin dashboard
- Building admin dashboard
- Customer support ticket management
- Staff replies and ticket tracking
- Building request submissions
- Blueprint upload and approval workflow
- Customer blueprint tracking
- Google Sheets integration
- Google Drive integration

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets
- Google Drive
- GitHub
- Netlify

**Backend:** Google Apps Script

**Database:** Google Sheets

**File Storage:** Google Drive

## Security

- Protect administrator and staff credentials.
- Do not expose private API keys or passwords.
- Restrict access to backend resources.
- Keep sensitive configuration in secure properties.
